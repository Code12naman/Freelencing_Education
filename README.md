# Vardhani Classes — Premium Institutional Website

> **Gwalior, Madhya Pradesh** | Specializing in Senior Secondary Science (Class 11 & 12) and NEET-UG Medical Preparation.

A custom-designed, production-grade institutional website built with an editorial and academic aesthetic inspired by prestigious universities and publications.

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript, Vite 6, Tailwind CSS, Lucide React, Framer Motion
- **Backend:** Node.js, Express.js, TypeScript (`server/` directory)
- **Database:** MongoDB & Mongoose Schema (`server/src/models/Enquiry.ts`)
- **Deployment:** Vercel configuration (`vercel.json`), Render/Railway ready

---

## 💻 Getting Started Locally

### Frontend Development
```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

### Backend Server (Optional)
```bash
cd server
npm install
npm run dev
```

---

## 🌐 Deploy to Vercel
1. Push this repository to GitHub.
2. Import repository on [Vercel](https://vercel.com).
3. Framework preset: **Vite**.
4. Output directory: `dist`.
5. Deploy!
